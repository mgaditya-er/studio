# **App Name**: AlbumAce

## Core Features:

- Intelligent Face Grouping: Detect faces, assign IDs, and group faces across photos to identify people. A tool flags the low-quality faces and the duplicates.
- Automatic Captioning: Generates natural language captions for each photo, identifying people (Person A, Person B, etc.) and the activity.
- Smart Theming: Classify each photo into event themes such as 'Group Selfie', 'Landscape', 'Food', using generative AI to assess.
- Event Summarization: Uses generative AI as a tool to assemble a fun and engaging summary, plus suggestion of highlight captions, after the upload of all photos.
- Event Creation & Management: Admin users can create events, which generates a unique code and QR code. They can also see the users who joined the event.
- Easy Join: Users can join albums by scanning the QR code or entering the unique code.
- Personalized Viewing: Photos can be viewed through multiple options: 'My Photos' or 'Group Photos'.

## Style Guidelines:

- Primary color: Muted teal (#74B49B), providing a sense of calm and sophistication, inspired by natural environments like water and sky, reflecting the shared experiences captured in the app. DO NOT SUGGEST TEAL, unless the user explicitly requests it.
- Background color: Very light, desaturated teal (#E8F0ED), complementing the primary color for a clean, airy feel.
- Accent color: Coral (#F07F6A), adds a pop of energy and excitement, creating visual interest without overwhelming the user.
- Font pairing: 'Belleza' (sans-serif) for headlines, 'Alegreya' (serif) for body text.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use minimalist and clear icons to represent different event themes and actions.
- Subtle transitions and animations to provide smooth user experience when navigating through albums and photos.
